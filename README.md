# VibeOS

Native iOS + Android theme platform for complete phone looks, widgets, icons, Live Worlds, AI theme creation, daily drops, premium subscriptions, limited-time offers, push notifications and analytics.

## Product pillars

- Premium dark glass design — no default platform-looking primary UI.
- Discover-first theme feed with complete look previews.
- Live Worlds with motion/touch/day-night behavior.
- Theme installation flows adapted to each OS capability.
- Dynamic catalog, daily drops and limited-time offers.
- Firebase Analytics / Crashlytics / Cloud Messaging integration points.
- RevenueCat subscription/paywall integration points.
- Shared event names and remote-config contract across iOS and Android.

> Platform note: Android supports a real `WallpaperService` live wallpaper. iOS exposes interactive previews and exported wallpaper/Live Photo workflows; the app never claims it can bypass iOS wallpaper restrictions.
